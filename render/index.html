Render Math

Paste LaTeX / Markdown (with math) here and see a live preview. Typst support is a placeholder for now.

Notes

  • Auto-detection heuristics: LaTeX markers (\\begin, $$, \\[) will favor LaTeX rendering; markdown markers (#, lists, fenced code) will favor Markdown with math support.
  • Typst: in-browser Typst rendering requires a WebAssembly build and is not included in this initial change. A placeholder option is provided; let me know if you want Typst WASM included now.
  • KaTeX is used to render math (fast, client-side). Markdown rendering uses markdown-it + markdown-it-katex so inline $...$ and $$...$$ work inside Markdown.
